# 依頼 1: 返却の期限に 3 日の猶予を入れる

返却が 1 日遅れただけで次の貸出を断られる、という苦情が社員から続いている。総務規程 第 3 条を改め、返却の期限のあとに 3 日の猶予を置くことにした。

- 貸出はどの種類でも、返却の期限から 3 日を過ぎたときに、はじめて期限を過ぎた扱いにする（期限の 3 日後までは、これまでの「貸出中」と同じ扱い。4 日後から期限を過ぎた扱い）。
- 「期限を過ぎた貸出を持つ社員には新しく貸さない」というきまりも、画面や `status.json` の表示も、この新しい扱いに合わせる。
- 返却の期限の日付そのもの（貸出日 + 貸出の期間）は変えない。

これは既にある総務システムへの変更の依頼。これまでの機能を壊さないこと。採点のために `contract.md` の契約を守ること。
