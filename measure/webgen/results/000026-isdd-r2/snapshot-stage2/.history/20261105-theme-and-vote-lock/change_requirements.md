# 変更要件定義書: 配色の変更と投票操作の無効化（Polls Website）

本書は変更の記録である。正本の `docs/requirements.md` は書き換えない（実装後に `isdd-build` の実装後レビューが反映する）。
依頼の出どころ: `REQUEST.md`（変更 1）。区分は各行の `[追加]` と `[削除]`。

## 1. 目的・前提

### 目的

画面の配色を依頼の指定（背景 light yellow、部品 dark slate gray）に変える。投票済みの投票テーマでは投票の操作を無効にし、「You have already voted」を表示する。それ以外の既存の機能（投票テーマの閲覧、確認つきの投票、結果の表示）は変えない。

既存の目的（`docs/requirements.md` 1）は変わらない。

### 用語集

変更なし。既存要件定義書 `docs/requirements.md` 1 を参照。

### システムの形態

変更なし。既存要件定義書 `docs/requirements.md` 1 を参照（GUI）。
