# 備品台帳

会社の備品の台帳と貸出状況を 1 つのアプリで見られるようにします。今回の段では、備品の登録・修正・削除と、貸出状況（すべて空き）の閲覧ができます。

## 起動方法

1. 準備（最初に 1 回）: `bash setup.sh`
   仮想環境を `.venv` に作り、依存と E2E 用の Chromium を入れます。
2. 起動: `bash run.sh`
   既定では `http://サーバーのアドレス:8000/` で待ち受けます。

環境変数（省略可）:

| 名前 | 用途 | 既定値 |
|---|---|---|
| `PORT` | 待ち受けポート | 8000 |
| `HOST` | 待ち受けアドレス | 0.0.0.0 |
| `DATA_DIR` | データ（SQLite の DB と秘密鍵）の置き場所 | `./data` |
| `SESSION_IDLE_TIMEOUT_SECONDS` | 操作しないまま自動ログアウトするまでの秒数 | 1800 |

社内ネットワークからだけ開くよう、サーバーのファイアウォールで `PORT` を社内に限ってください。

## 初回の導入

社員に URL を知らせる前に、担当者が最初のアカウントを登録してください。最初に登録したアカウントが担当者になり、2 件目以降は社員になります。

1. 貸出状況の画面の「アカウント登録」から、社員番号（6 桁の数字）、名前、パスワード（8 文字以上）を入力して「登録」。
2. 「ログイン」から登録した社員番号とパスワードでログインし、「備品を登録」から備品を登録します。

## 貸出と返却

担当者は貸出状況の画面で、空きの備品の行の「貸出」から借りる社員と貸出日（既定は今日。未来の日付は不可）を登録します。貸出中の備品の行には「返却」があり、確認で「はい」を選ぶと貸出の記録を消して空きに戻します（返却した記録は残りません）。貸出中の備品は削除できません。社員と未ログインの利用者は、貸出状況の画面で貸出中の備品と借りている社員、貸出日を確認できます。

## アカウントの管理（担当者だけ）

担当者は貸出状況の画面の「アカウントの一覧」から、社員番号、名前、担当者か社員かを見られます。行の操作で次のことができます。

- 「担当者にする」「担当者から外す」: 社員を担当者にする、または担当者を社員に戻す。担当者が 1 人だけのときは外せません。
- 「パスワード再設定」: 社員の新しいパスワード（8 文字以上）を設定します。設定後は古いパスワードではログインできません。設定したパスワードは担当者が本人に伝えてください。入力欄は入力エラーの後も値が残るため、共用の PC では操作後にブラウザを閉じてください。
- 「削除」: アカウントを削除します（記録は残りません）。備品を借りている社員と、担当者が 1 人だけのときの担当者は削除できません。削除した社員はログインできず、貸出の登録で選ぶ社員の一覧にも出ません。

## 初期ユーザー

初期ユーザーは作りません。初回の導入で、担当者が上の手順により最初のアカウントを画面から登録します。

## 注意

- 登録の画面で入力を誤ったとき、入力したパスワードはそのまま画面に残ります（入力値を消さない仕様のため）。共用の PC では操作後にブラウザを閉じてください。
- 削除した備品の記録は残りません。
- 移行は、既存の Excel から画面で手入力してください（取り込み機能はありません）。
