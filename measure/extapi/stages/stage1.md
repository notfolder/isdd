# 依頼: 仕入先の在庫を自社の画面で見たい

うちはねじや金物の卸をしています。仕入先の「まるいち物産」が在庫照会の API を出してくれたので、それを使って、まるいち物産の商品と在庫数を自社の画面で一覧できるようにしてください。

使えるようにしてほしいこと:

- まるいち物産の商品（商品コード、商品名、在庫数）を取り込んで、一覧で見る。
- 商品ごとに、うちの売価（円）を入力して、一覧に出す。

まるいち物産からもらった API の仕様書と接続情報は、`supplier-api/` に置いてあります。検証環境は自由に呼び出してよいそうです。

採点のために `contract.md` の契約（起動方法、環境変数、採点用の接点）を守ること。
