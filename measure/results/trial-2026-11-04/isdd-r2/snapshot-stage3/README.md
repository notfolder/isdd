# 備品台帳・貸出状況

会社の備品の台帳と貸出の記録を 1 つにまとめ、社員が貸出状況を自分で確かめられるアプリです。Python 3.12 の標準ライブラリと SQLite だけで動き、外部パッケージは使いません。

## 起動方法

社内の Linux サーバーで、リポジトリのディレクトリに移動して次を実行します。

```bash
bash setup.sh
PORT=8000 DATA_DIR=./data bash run.sh
```

- `setup.sh` は 1 回だけ実行します。Python 3.12 以上と sqlite3 が使えるかを確かめます。
- `run.sh` は起動します。ブラウザで `http://<サーバーの名前>:8000/` を開きます。
- 社内ネットワークからだけ開けるようにしてください。インターネットへは公開しない前提です。

### 環境変数

| 名前 | 用途 | 既定値 | 必須 |
|---|---|---|---|
| `PORT` | 待ち受けるポート | 8000 | 不要 |
| `DATA_DIR` | データベース（`isdd.sqlite3`）を置くディレクトリ。無ければ作ります | `./data` | 不要 |
| `SESSION_IDLE_TIMEOUT_SECONDS` | 操作しないまま自動でログアウトするまでの秒数 | 1800 | 不要 |

パスワードなどの秘密情報は設定に無く、ファイルにも書きません。

## 初期ユーザー（最初の担当者の登録）

初期ユーザーはありません。社員に URL を知らせる前に、担当者が最初のアカウントを登録してください。

1. `bash run.sh` で起動し、ブラウザで `/accounts/register/` を開きます。
2. 社員番号（6 桁の数字）、名前、パスワード（8 文字以上）を入力して登録します。
3. アカウントが 1 件も無いときに登録した人は自動で「担当者」になります。2 件目以降は「社員」です。
4. 以降は、社員が自分でアカウントを登録できます。担当者はアカウントの一覧から、担当者の付け外し、パスワードの再設定、アカウントの削除ができます。

利用者は社員と担当者の合計で 50 人までです。

## 使い方

- 貸出状況（トップ）: 誰でも見られます。管理番号の昇順で、空きか貸出中か、借りている社員の名前と貸出日を表示します。
- 担当者は、備品の登録・修正・削除、貸出、返却ができます。
- 社員は貸出状況を見られます。操作のボタンは表示されず、操作の要求も拒否されます。
- 移行: 既存の Excel の内容は、担当者が画面から手で入力します。取り込み機能はありません。

## テスト

```bash
python3 -m unittest discover -s tests/unit
python3 scripts/isdd/unittest_junit.py -s e2e -o e2e/results/e2e.xml
```

E2E テストは、空のデータディレクトリでアプリを別プロセスとして起動して確かめます。サーバーを手で起動しておく必要はありません。

## ファイル構成

- `app/`: アプリ本体（HTTP の処理、業務ロジック、画面の HTML、DB）
- `tests/unit/`: 単体テストと結合テスト
- `e2e/`: HTTP 経由の E2E テスト
- `docs/`: 要件定義書、詳細設計書、対応表
- `scripts/isdd/`: 対応表と受け入れ判定のチェッカー（isdd-setup が導入）
