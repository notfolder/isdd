# 依頼（段 1）: 備品の台帳と貸出状況の閲覧

会社の備品の台帳と貸出の記録を 1 つのアプリにまとめたい。今は管理用 Excel が複数あって、どれが最新か分からず、記録が食い違ったり消えたりしている。社員が「どの備品を誰が借りているか」を担当者に問い合わせないと分からず、担当者は 1 回 15 分かけて調べている。

今回の段では、次を使えるようにしてほしい。

- 社員が自分でアカウントを登録する（社員番号 6 桁の数字、名前 30 文字以内、パスワード 8 文字以上。社員番号は重複不可）。アカウントが 1 件も無いときに登録した人は自動で「担当者」になり、2 件目以降は「社員」になる。
- 社員番号とパスワードでログイン・ログアウトする。失敗したときは、社員番号とパスワードのどちらが違うかを示さない。操作しないまま 30 分たったら自動でログアウトする。
- 担当者が備品を登録・修正・削除する（管理番号は半角の英数字とハイフンで 20 文字以内、重複不可。備品名は 50 文字以内）。
- 誰でも（ログインしなくても）貸出状況を見られる。全備品の管理番号、備品名、空きか貸出中か、借りている社員の名前、貸出日を一覧で見る。貸出の登録はまだ無いので、この段ではすべて「空き」でよい。
- 備品の登録・修正・削除は担当者だけができる。社員やログインしていない人には、ボタンを出さないだけでなく、操作の要求も受け付けない。

利用者は社員と担当者の合計で 50 人まで、備品は数百件まで。社内のサーバーで動かし、社内のネットワークからだけ開く。無償のものだけを使う。画面はブラウザで開く GUI だけで、Web API やバッチは要らない。

採点のために `contract.md` の契約（起動方法、URL、画面の要素の id、文言）を守ること。
