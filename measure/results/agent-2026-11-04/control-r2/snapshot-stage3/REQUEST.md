# 依頼（段 3）: アカウントの管理

段 2 のアプリに、担当者がアカウントを管理する機能を足してほしい。

- 担当者が全アカウントの一覧（社員番号、名前、担当者か社員か）を見る。
- 担当者が、アカウントを担当者にする、または担当者から外す。
- 社員がパスワードを忘れたら、頼まれた担当者がそのアカウントの新しいパスワード（8 文字以上）を設定して本人に伝える。再設定の後は、古いパスワードではログインできない。
- 担当者が、退職などで使わなくなったアカウントを削除する。削除したアカウントではログインできず、貸出の登録で選ぶ社員の一覧にも出ない。
- 備品を 1 台以上借りている社員のアカウントは削除できない。
- 担当者が 1 人だけのときは、その人を担当者から外す操作と、その人のアカウントを削除する操作を受け付けない（担当者を 0 人にしない）。

アカウントの一覧とその操作は担当者だけができる。社員やログインしていない人の要求は受け付けない。

採点のために `contract.md` の契約を守ること。段 1・2 の機能を壊さないこと。
