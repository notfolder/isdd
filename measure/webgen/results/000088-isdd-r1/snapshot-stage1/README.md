# Species Biology Database

生物種ごとの生物学的情報（分類群、生息環境、食性、寿命、体重、保全状況など）を閲覧・検索・絞り込み・登録・修正・削除する Web サイトです。Python 3.9 以上（推奨は 3.12）と標準ライブラリだけで動きます。外部パッケージは使いません。

## 起動方法

```bash
bash setup.sh                 # Python のバージョン確認と保存先の作成（初回だけ）
PORT=8000 bash run.sh         # Web サーバーを前面で起動する
```

起動したら Web ブラウザで http://127.0.0.1:8000/ を開きます。止めるときは端末で Ctrl+C を押します。

- `PORT`: 待ち受けポート（省略時は 8000）
- `DATA_DIR`: データベース（`species.db`）を置くフォルダ（省略時はプロジェクトの `data` フォルダ）。フォルダが無ければ作ります。
- 初回起動時（データベースがまだ無いとき）は、サンプルの生物種 12 件が入ります。2 回目以降の起動ではサンプルは追加されません。

認証はありません。サーバーは 127.0.0.1 だけで待ち受けます。

## 画面

上部のメニューから次の画面に移動できます。

| メニュー | 画面 | 内容 |
|---|---|---|
| Browse species | `/` | 一覧。検索欄（学名・和名・説明）と、分類群・生息環境・食性・保全状況の選択欄で絞り込めます。Clear で条件を消します。 |
| Add species | `/species/new` | 生物種を登録します。必須項目は「*」の付いた項目です。 |
| 一覧の和名 | `/species/<id>` | 詳細。Edit で修正、Delete で削除（確認ダイアログで OK のときだけ削除）。 |

## テスト

```bash
python3 -m unittest discover -s tests -p "test_*.py"                  # 単体テスト
python3 scripts/isdd/unittest_junit.py -s e2e -t . -o e2e/results/e2e.xml   # E2E テスト（実サーバーを起動して確かめる）
```

## 構成

- `src/core/`: 選択肢、サンプルデータ、入力チェック、SQLite への保存（画面を知らない）
- `src/web/`: HTTP サーバー、画面の HTML、スタイルシート（`static/style.css`）
- `docs/`: 要件定義書、詳細設計書、対応表（isdd の正本）
- `scripts/isdd/`: 対応表チェックのスクリプト（isdd-setup が導入）
