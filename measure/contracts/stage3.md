# 採点の契約（段 3: アカウントの管理、「管理者」から「管理者」への改称。段 2 の契約を書き換えた完全版）

採点は、この契約に沿って自動で行う。契約に無いことは自由に決めてよい。契約を守らないと、機能が正しくても採点で落ちる。

## 起動

- プロジェクトルートに `run.sh` を置く。`bash run.sh` で Web アプリが起動し、環境変数 `PORT`（既定 8000）で待ち受ける。
- 環境変数 `DATA_DIR` にデータ（DB ファイルなど）を置く。無ければ作る。空なら、備品もアカウントも 0 件の状態で始まる。
- 環境変数 `SESSION_IDLE_TIMEOUT_SECONDS` で、操作しないまま自動でログアウトするまでの秒数を変えられる（既定 1800）。
- 起動に必要な準備（依存の導入など）は `bash setup.sh` で行う。採点の前に 1 回だけ実行する。
- 外部のサービスや有償のものを使わない。Python 3.12 と無償のライブラリ、SQLite などのファイル DB で足りるようにする。

## 画面の URL

| 画面 | URL |
|---|---|
| 貸出状況（トップ） | `/` |
| アカウント登録 | `/accounts/register/` |
| ログイン | `/login/` |
| 備品の登録 | `/equipment/new/` |
| アカウントの一覧 | `/accounts/` |

貸出・返却は、貸出状況の一覧の行のボタンから行う（貸出の登録画面の URL は自由）。管理者の付け外し・パスワード再設定・アカウント削除は、アカウントの一覧の行のボタンから行う（URL は自由）。

備品の修正・削除は、貸出状況の一覧の行のボタンから行う（URL は自由）。

## 画面の要素（id・文言は一致させる）

- 入力欄の id: 社員番号 `id_employee_number`、名前 `id_name`、パスワード `id_password`、管理番号 `id_equipment_number`、備品名 `id_name`、借りる社員 `id_borrower`（select。選択肢の表示は「名前（社員番号）」で、社員番号は 7 桁）、貸出日 `id_lent_on`（`YYYY-MM-DD`、既定は日本時間の今日）、新しいパスワード `input[name=new_password]`。
- ボタンの文言: アカウント登録「登録」、ログイン「ログイン」、ログアウト「ログアウト」、備品の登録と修正の保存「保存」、貸出の登録「登録」、行の操作「修正」「削除」「貸出」（空きの備品）「返却」（貸出中の備品）、アカウントの一覧の行の操作「管理者にする」「管理者から外す」「パスワード再設定」「確定」「削除」。管理者だけに出す。
- 貸出の登録画面には `.lending-equipment` 要素に「備品: <管理番号> <備品名>」を出す。
- リンクの文言: 貸出状況の画面に「ログイン」「アカウント登録」（ログインしていないとき）、「アカウントの一覧」（管理者だけ）。備品の登録画面への入口は「備品を登録」（管理者だけ。ボタンでもリンクでもよい）。
- アカウントの一覧の表は `tbody tr` で、各行に `data-employee-number="<社員番号>"` を付け、3 列目に「管理者」または「社員」を出す。「パスワード再設定」を押すと、その行に `input[name=new_password]` と「確定」ボタンが出る。パスワードが短いときのエラーは、その行の `.field-error` に出す。
- 管理者の付け外し、アカウントの削除も、確認ダイアログで「はい」のときだけ行う。
- 画面のどこにも「担当者」という語を残さない（段 3 で「管理者」に改称）。
- 入力欄ごとのエラーは、入力欄を含む `.field` 要素の中の `.field-error` 要素に出す。入力した値は消さない。
- 画面全体のエラー（ログインの失敗、他の管理者が先に更新した）は `.error` 要素に出す。
- 操作の結果の知らせ（「この操作は管理者だけが行えます」など）は `.message` 要素に出す。
- ログイン中は `.current-user` 要素に名前を出す。
- 貸出状況の表は `tbody tr` で、各行に `data-equipment-number="<管理番号>"` を付け、管理番号の昇順に並べる。行には管理番号、備品名、「空き」または「貸出中」、借りている社員の名前、貸出日（`YYYY-MM-DD`）の列を出す。備品が 0 件なら「備品は登録されていません」と出す。ログインしていないときは画面にボタンを出さない（「ログイン」「アカウント登録」はリンク）。社員には行のボタンを出さない。
- 削除と返却は、ブラウザの確認ダイアログ（`window.confirm`）で「はい」のときだけ行う。

## 文言（完全一致）

| 場面 | 文言 |
|---|---|
| 社員番号の形式（段 2 で 7 桁に変更） | 社員番号は 7 桁の数字で入力してください |
| 社員番号の重複 | この社員番号は既に登録されています |
| 名前が空 | 名前を入力してください |
| 名前が長い | 名前は 30 文字以内で入力してください |
| パスワードが短い | パスワードは 8 文字以上で入力してください |
| アカウント登録の成功（ログイン画面に移って表示） | 登録しました。ログインしてください |
| ログインの失敗 | 社員番号またはパスワードが違います |
| 管理者以外の操作（貸出状況の画面に戻して `.message` に出す。ログインしていなければログイン画面へ） | この操作は管理者だけが行えます |
| 管理番号の形式 | 管理番号は半角の英数字とハイフンで 20 文字以内で入力してください |
| 管理番号の重複 | この管理番号は既に使われています |
| 備品名が長い | 備品名は 50 文字以内で入力してください |
| 他の管理者が先に更新・削除した（修正の保存で `.error` に出す） | 他の管理者が先にこの備品を更新しました。貸出状況の画面から開き直してください |
| 貸出中の備品の削除（貸出状況の画面の `.message` に出す） | この備品は貸出中のため削除できません。先に返却を処理してください |
| 借りる社員が未選択（`.field-error`） | 借りる社員を選んでください |
| 未来の貸出日（`.field-error`） | 貸出日に未来の日付は入力できません |
| 貸出中の備品の貸出（貸出状況の画面の `.message` に出す） | この備品は既に貸出中です |
| 返却済みの備品の返却（貸出状況の画面の `.message` に出す） | この備品は既に返却されています |
| 借りている社員の削除（アカウントの一覧の `.message` に出す） | この社員は備品を借りているため削除できません。先に返却を処理してください |
| 管理者が 0 人になる操作（アカウントの一覧の `.message` に出す） | 管理者が 1 人もいなくなるため、この操作はできません |
| パスワードが短い（その行の `.field-error`） | パスワードは 8 文字以上で入力してください |
