1. A1: 要件と設計を最新の 1 組として保たない理由

## D. 評価と効果の裏づけ

公式の評価結果を 2026-11-22 に調べた。分かったこと:

- 評価器は今の版（main、v2.11.x）に入っていない。v1 のブランチ、退避用のブランチ、未マージの PR 753 番にある。置き場所は Issue 933 番で未決。
- v2.6.18 以降（classic と express が入った版）と v2.11.4 の公開結果は見つからなかった。
- v2 の公開結果でいちばん新しいのは PR 753 番の 2026-08 の実行。sci-calc は Claude Code と Opus 級で 88/88 を 3 回、88〜112 分、51〜58 ドル。既存コードの題材 2 つ（不具合の修正、機能の追加）は 3 件中 3 件。
- 対照（AI-DLC を使わない場合）との比較は出ていない。Issue 684 番で「最も価値の高い追加」と提案された段階。
- 評価器の依頼者役は、技術の指定を知っていて承認寄りに即答する AI。あいまいな依頼や質問の質を測る題材は無い。
- AWS の事例の数字（工数 68〜87% 減など）は、従来の見積もりとの比較か逸話。
