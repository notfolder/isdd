# 依頼: 総務システムの文書を整える

総務システム（機能は 60 個。貸出、予約、申請）には、要件定義書も設計書も無い。作った人が異動して、仕様を聞ける人が居なくなった。これから変更を重ねていくので、今のうちに文書を整えたい。

- 今のコードから、システム全体の要件定義書、詳細設計書、設計とコードの対応表を作る。
- 範囲は、60 個の機能すべてと、共通の部分（ログイン、社員、操作の記録）。
- コードは変えない。今の動きを、そのまま文書にする。
- 総務のきまりは `docs/soumu-rules.md` にある。機能の足し方は `docs/module-guide.md` にある。
- あとで「どのきまりが、どの機能の、どこに書かれているか」を探せるようにしておきたい。
