# 備品台帳・貸出状況

会社の備品の台帳と、社員による貸出状況の閲覧を 1 つのアプリにまとめたものです。社内サーバーで動かし、社内ネットワークからだけ開きます。

## 起動方法

Python 3.12 が必要です。

1. 導入（初回に 1 回）

   ```
   bash setup.sh
   ```

2. 起動

   ```
   bash run.sh
   ```

   ブラウザで `http://サーバーのアドレス:8000/` を開きます。

### 設定（環境変数）

| 名前 | 用途 | 既定値 |
|---|---|---|
| `PORT` | 待ち受けポート | 8000 |
| `HOST` | 待ち受けアドレス | 0.0.0.0 |
| `DATA_DIR` | DB（`equipment.db`）と署名鍵（`secret_key`）の置き場所 | `./data` |
| `SESSION_IDLE_TIMEOUT_SECONDS` | 無操作で自動ログアウトするまでの秒数 | 1800 |

社内ネットワークからだけ開くには、サーバーの前段のファイアウォールで、社内の範囲以外からの接続を止めてください。

## 初期ユーザー

初期ユーザーは無く、初期パスワードもありません。導入の手順は次のとおりです。

1. 社員に URL を知らせる前に、担当者が最初のアカウントを登録する（`/accounts/register/`）。最初に登録したアカウントが担当者になります。
2. 2 件目以降に登録したアカウントは社員になります。
3. 社員に URL を知らせる。

## 使い方

- 貸出状況（`/`）: 誰でも見られます。備品の管理番号、備品名、状況（空き・貸出中）、借りている社員、貸出日を一覧で表示します。
- 社員番号は 7 桁の数字です。アカウント登録とログインで使います。
- 担当者は、ログイン後に次の操作を行えます。
  - 「備品を登録」から備品を登録し、一覧の「修正」「削除」で直したり消したりできます。貸出中の備品は削除できません。
  - 空きの備品の行の「貸出」から、借りる社員と貸出日（既定は今日。未来の日付は不可）を登録します。
  - 貸出中の備品の行の「返却」で返却を処理します（確認で「はい」を選ぶと、貸出の記録は消えて空きに戻ります）。
- 担当者が修正画面を開いてから保存するまでに、別の担当者が同じ備品を修正または削除していた場合、保存は拒否されます。貸出状況の画面から開き直してください。
- 無操作が 30 分続くと、自動でログアウトします。

### 既存のデータベースの更新

起動時に、既存のデータベース（`DATA_DIR/equipment.db`）へ版番号の列と貸出の表を自動で足します。既存のデータは消えません。社員番号は 6 桁のまま残っているアカウントは、7 桁の番号では使えないため、必要なら担当者が登録し直してください。

## テスト

```
.venv/bin/python -m pytest tests -q
.venv/bin/python -m pytest e2e -q --junitxml=e2e/results/e2e.xml
```

E2E は一時の DATA_DIR で本物のサーバーを起動し、Chromium で操作します。
