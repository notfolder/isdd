# 備品台帳と貸出状況の閲覧

会社の備品の台帳と貸出状況を 1 つのアプリで見られるようにする Web アプリです（段 1: 備品の登録・修正・削除と、貸出状況の一覧。貸出の登録は次の段で作ります）。

## 起動方法

### 必要なもの

- Python 3.12（`python3 --version` で確認）
- 社内の Linux サーバー。コンテナは使いません。

### 初回の導入

1. プロジェクトの直下で、仮想環境と依存を 1 回だけ作ります。

   ```bash
   bash setup.sh
   ```

2. 起動します。待ち受けポートは環境変数 `PORT`（既定 8000）です。

   ```bash
   bash run.sh
   ```

3. ブラウザで `http://<サーバー>:8000/` を開きます。

### 環境変数

| 名前 | 用途 | 既定値 |
|---|---|---|
| `PORT` | 待ち受けポート | 8000 |
| `DATA_DIR` | データ（`app.db` と秘密鍵 `secret_key`）の置き場。無ければ作ります | プロジェクト直下の `data` |
| `SESSION_IDLE_TIMEOUT_SECONDS` | 操作しないまま自動でログアウトするまでの秒数（正の整数） | 1800 |

例: `PORT=8080 DATA_DIR=/var/lib/equipment SESSION_IDLE_TIMEOUT_SECONDS=1800 bash run.sh`

## 初期ユーザー

初期ユーザーは置きません。アカウントが 1 件も無い状態で最初に登録した人が「担当者」になります。

### 最初のアカウント（担当者）の登録

アカウントが 1 件も無い状態で最初に登録した人が「担当者」になります。2 件目以降に登録した人は「社員」です。

社員に URL を知らせる前に、担当者が次の手順で最初のアカウントを登録してください。

1. `/accounts/register/` を開き、社員番号（6 桁の数字）、名前、パスワード（8 文字以上）を入力して「登録」を押します。
2. 「登録しました。ログインしてください」と表示されたら、`/login/` で同じ社員番号とパスワードでログインします。
3. 「備品を登録」から備品を登録します。

## 画面

| 画面 | パス |
|---|---|
| 貸出状況（トップ） | `/` |
| アカウント登録 | `/accounts/register/` |
| ログイン | `/login/` |
| 備品の登録 | `/equipment/new/` |

備品の修正と削除は、貸出状況の一覧の行のボタンから行います（担当者だけ）。

## テスト

```bash
.venv/bin/python -m unittest discover -s tests/unit
python3 scripts/isdd/unittest_junit.py -s e2e -o e2e/results/e2e.xml
```

E2E は一時の DATA_DIR と空いたポートでサーバーを起動して確かめます。結果は `e2e/results/e2e.xml` に出ます（git 管理外）。
