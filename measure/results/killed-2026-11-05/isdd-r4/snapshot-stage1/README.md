# 備品台帳と貸出状況の閲覧

会社の備品の台帳と、備品の貸出状況（この段では全件「空き」）を 1 つのアプリで見る。社員は誰でも一覧を見られ、担当者が備品を登録・修正・削除する。

## 起動方法

1. 初回だけ準備する（依存の導入と、E2E 用の Chromium の導入）:

   ```bash
   bash setup.sh
   ```

2. 起動する:

   ```bash
   bash run.sh
   ```

   ブラウザで `http://<サーバー>:8000/` を開く。

### 環境変数

| 名前 | 用途 | 既定値 |
|---|---|---|
| `PORT` | 待ち受けポート | 8000 |
| `DATA_DIR` | データ（DB ファイルと秘密鍵）の置き場所。無ければ作る | `./data` |
| `SESSION_IDLE_TIMEOUT_SECONDS` | 操作しないまま自動でログアウトするまでの秒数 | 1800 |

## 初期ユーザー

初期ユーザーは無い。最初に登録したアカウントが担当者になる（下の導入手順）。

## 初回の導入手順（担当者の登録）

社員に URL を知らせる前に、担当者が最初のアカウントを登録する。アカウントが 1 件も無いときに登録した人が担当者になり、2 件目以降は社員になる。

1. `bash run.sh` で起動する。
2. `/accounts/register/` を開き、社員番号（6 桁の数字）、名前（30 文字以内）、パスワード（8 文字以上）を入れて登録する。
3. ログインして、「備品を登録」から備品を登録する。

## 使い方

- 貸出状況（`/`）: ログインしていなくても見られる。管理番号の昇順。
- ログイン（`/login/`）、ログアウト（画面上部）。操作しないまま 30 分たつと自動でログアウトする。
- 担当者だけが「備品を登録」「修正」「削除」を使える。
