# まるいち物産 在庫照会 API 仕様書（v1）

発行: まるいち物産 情報システム部　　版: 1.4

取引先のシステムから、当社の商品と在庫数を照会するための API です。

## 接続先

- 検証環境と本番環境があります。URL と資格情報は、別紙の接続情報で取引先ごとにお渡しします。
- 検証環境は、開発と試験のために自由に呼び出して構いません（データは試験用です）。
- 以下のパスは、接続先の URL のあとに続けます（例: `http://<接続先>/v1/items`）。

## 認証

`POST /v1/auth/token`

要求（JSON）:

```json
{"client_id": "<クライアント ID>", "client_secret": "<クライアントシークレット>"}
```

応答（200）:

```json
{"access_token": "<トークン>", "token_type": "Bearer", "expires_in": 30}
```

- 照会の要求には `Authorization: Bearer <トークン>` を付けます。
- トークンは `expires_in` 秒が過ぎるか、一定回数の照会に使うと失効します。失効したトークンには `401`（`{"error": "token_expired"}`）を返すので、トークンを取り直してください。
- 資格情報が違うときは `401`（`{"error": "invalid_client"}`）、トークンが違うときは `401`（`{"error": "invalid_token"}`）を返します。

## 商品と在庫の照会

`GET /v1/items?page=<ページ番号>&per_page=<1 ページの件数>`

| パラメータ | 説明 |
|---|---|
| `page` | ページ番号。1 から。省略時は 1 |
| `per_page` | 1 ページの件数。省略時は 20、上限は 100 |

応答（200）:

```json
{
  "items": [
    {"code": "MB-00001", "name": "六角ボルト M8×25", "stock": 120}
  ],
  "page": 1,
  "per_page": 20,
  "total": 180
}
```

| 項目 | 説明 |
|---|---|
| `code` | 商品コード（当社の管理番号。変わりません） |
| `name` | 商品名 |
| `stock` | 在庫数（0 以上の整数） |
| `total` | 条件に合う商品の総数 |

- 商品は商品コードの昇順に返します。
- 廃番になった商品は返しません。

## 回数の制限

- 照会はトークンごとに 1 秒あたり 3 回までです。
- 超えたときは `429`（`{"error": "rate_limited"}`）を返し、`Retry-After` ヘッダーに待つ秒数を入れます。その秒数を待ってから、同じ要求をやり直してください。
- `Retry-After` を待たずに要求を繰り返す取引先は、利用を停止することがあります。

## 障害

- 当社の保守や障害のあいだは `503`（`{"error": "service_unavailable"}`）を返します。時間をおいて照会してください。
