# 題材 needfit の本番の規則

本番の実行の前にコミットする。コミットのあとは変えない。変えたときは、変える前の回を本番に混ぜない。

## 問い

依頼が業務の問題とずれていて、課題に結びつかない機能も混ざっているとき、やり方によって、業務の問題が解決するか、不要な機能を作らずに済むか、必要な機能を削らないか、が変わるか。

## 群と回数

| 群 | 指示 | 回数 |
|---|---|---|
| バイブコーディング | `--arm control`（質問してよい、とだけ伝える） | 6 |
| 一文つき | `--arm control --ask-first`（作り始める前に質問する、の一文） | 6 |
| isdd | `--arm isdd`（isdd-spec と isdd-build） | 6 |

isdd と一文つきの差がこの題材の主題なので、3 群とも 6 回にする（`EVALUATION-REVIEW.md` 7 章）。回数は足さない。6 回は予算で決めた数で、同等を示せる数ではない。

共通の条件: 開発のモデルは `claude-opus-5-5`、依頼者役は `claude-sonnet-5-5`、`--max-rounds 20`、`--timeout-min 45`、段は 1 だけ。isdd の版と、題材・実行器の中身の要約は、回ごとの `summary.json` の `conditions` に残る。

実行の順は、18 本を乱数（種 20261123）で並べ替え、4 本ずつ同時に回す。

## 指標

| 指標 | 出し方 |
|---|---|
| 主な指標: 業務のシナリオの達成 | 採点結果の `scenario`。群ごとに「達成した回数 / 割り当てた回数」 |
| 業務の問題に関わるテスト | `categories.need`（8 件中） |
| 基本の機能 | `categories.base`（10 件中） |
| 必要な機能の欠落 | `categories.keep` が 0 の回数 |
| 不要な機能の実装 | `unneeded.count`（0〜3） |
| 費用と時間 | 開発の費用、依頼者役の費用、所要時間、依頼者が答えた回数を別々に出す |

総合点は作らない。全回の値を表に載せる。群の比較は、主な指標の達成回数を「バイブコーディング対 isdd」「一文つき対 isdd」の 2 組で並べ、参考としてフィッシャーの正確検定（両側）の値を添える。差が無かった組は「差は見つからなかった」と書き、「同等」とは書かない。

## 回の扱い

| 起きたこと | 扱い |
|---|---|
| 完了の印（STAGE_DONE）を作らずに終わった、時間切れ、アプリが起動しない | その群の出来として、そのまま採点して数える |
| 採点できなかった（`scoring_status` が `unscored`） | アプリを変えずに採点し直す。それでも採点できなければ「未採点」として載せ、点には数えない |
| 依頼者役の返事が取れなかった（`infra_incomplete`）、開発のモデルの呼び出しが結果を返さずに終わった | 基盤の障害。同じ番号で 1 回だけやり直し、障害の回も理由つきで載せる |
| 隠しテスト・台帳・ほかの回の作業フォルダに触れた（`leak_hits` が 1 件以上） | その回は無効として載せ、同じ番号で 1 回だけやり直す |
| isdd 群でスキルを呼ばず、文書も更新しなかった（`procedure_evidence` が偽） | 全回の集計に含める。手順を実施した回だけの集計を併記する |
| 利用上限で止まった | 実行器が回復を待って続ける。待ち時間は所要時間から除けないので、所要時間に注記する |

## 試し回し

本番の前に、バイブコーディングと一文つきを 1 回ずつ回した（`needfit-trial-*`）。目的は題材とテストの不備を直すことで、結果は本番に数えない。直した内容は下に書く。

試し回しの結果（本番に数えない）: バイブコーディングは業務のテスト 8 件中 0 件で不要な機能を 3 つ作り、一文つきは 8 件中 7 件で不要な機能は 0 だった。この 2 回は作業フォルダをホームの下に置いていて、利用者の共通ルール（質問は選択肢とおすすめを付けて出す、など）が読み込まれていた。

試し回しで直したこと:

| 直したこと | 中身 |
|---|---|
| 作業フォルダの場所 | ホームの下だと、ホームの `CLAUDE.md` と `~/.claude/CLAUDE.md` が開発の AI に読み込まれる。本番は `/Users/Shared/isdd-measure-work` で回す。実行器は、親フォルダに規則ファイルがあれば起動しない |
| 依頼者が答えた回数の数え方 | 開発側の応答に「?」があるかで数えていて、表で聞いた質問を数え落とした。依頼者が「続けてください」以外を返した回を数える形に直した |

依頼文、台帳、契約、隠しテストは、試し回しのあとに変えていない。
