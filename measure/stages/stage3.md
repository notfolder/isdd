# 依頼（段 3）: 「管理者」から「管理者」への改称と、アカウントの管理

段 2 のアプリに、次の変更と追加をしてほしい。

**変更（既存の機能）**: 役割の名称「担当者」を「管理者」に変える。画面の文言、ボタン、知らせの文（「この操作は担当者だけが行えます」「他の担当者が先に…」など）、一覧の表示のすべてで「担当者」という語を使わず「管理者」にする。権限の中身は変えない。

**追加**: 管理者がアカウントを管理する機能。

- 管理者が全アカウントの一覧（社員番号、名前、管理者か社員か）を見る。
- 管理者が、アカウントを管理者にする、または管理者から外す。
- 社員がパスワードを忘れたら、頼まれた管理者がそのアカウントの新しいパスワード（8 文字以上）を設定して本人に伝える。再設定の後は、古いパスワードではログインできない。
- 管理者が、退職などで使わなくなったアカウントを削除する。削除したアカウントではログインできず、貸出の登録で選ぶ社員の一覧にも出ない。
- 備品を 1 台以上借りている社員のアカウントは削除できない。
- 管理者が 1 人だけのときは、その人を管理者から外す操作と、その人のアカウントを削除する操作を受け付けない（管理者を 0 人にしない）。

アカウントの一覧とその操作は管理者だけができる。社員やログインしていない人の要求は受け付けない。

採点のために `contract.md` の契約（段 3 の版。役割の文言が変わっている）を守ること。変更した点以外の段 1・2 の機能を壊さないこと。
