# 依頼: 部品と消耗品の在庫の管理

工場の部品と消耗品の在庫を、Excel の台帳で管理しています。これを 1 つのアプリにしてください。使うのは資材係の 3 人で、社内のパソコンのブラウザから開きます。ログインは要りません。

## 台帳の列

今の Excel の台帳の列は次のとおりです。アプリでも同じ項目を持たせてください。品目は約 400 あります。

| 列 | 中身 |
|---|---|
| 品目コード | 半角の英数字とハイフン、20 文字以内。重複なし |
| 品名 | 50 文字以内 |
| 在庫数 | 今ある数 |
| 1 日の使用量 | 1 日に使う数のめやす |
| 納期日数 | 注文してから届くまでの日数 |
| 発注中の数 | 注文して、まだ届いていない数 |
| 最小発注数 | 1 回に注文できる最小の数 |
| 仕入先 | 仕入先の名前。50 文字以内 |
| 単価 | 1 個の値段（円） |
| 置き場所 | 棚の番号など。30 文字以内 |

数はすべて 0 以上の整数です。

## 作ってほしいこと

- 品目を登録・修正・削除する。
- 入庫（届いた数を在庫数に足す）と、出庫（使った数を在庫数から引く）を記録する。在庫数より多い数は出庫できない。
- 品目の一覧を見る。
- **在庫数が 10 以下になった品目に「要発注」の印を付ける。** 一覧で、要発注の品目がすぐ分かるようにしてほしい。

## ついでに付けてほしいこと

- 仕入先ごとに、月別の入庫の金額を集計して見られるようにする。
- 品目の一覧を CSV でダウンロードできるようにする。
- 品目に写真を 1 枚付けられるようにする。
- 出庫を記録するときに、使った人の名前を残し、品目ごとに出庫の履歴を見られるようにする。

採点のために `contract.md` の契約を守ってください。
