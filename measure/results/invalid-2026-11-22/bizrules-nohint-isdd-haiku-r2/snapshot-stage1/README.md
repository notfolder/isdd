# 備品の貸出管理

会社の備品の貸出を管理する Web アプリです。社員は貸出状況をログインせずに見られ、担当者が備品の登録・修正・削除と、貸出・返却の記録を行います。

## 動作環境

- Python 3.12
- 外部サービスや有償のソフトは使いません（Flask、Waitress、SQLite）。

## 準備

採点や初回の利用の前に 1 回だけ実行します。

```bash
bash setup.sh
```

仮想環境 `.venv` を作り、`requirements.txt` の依存と、E2E テスト用のブラウザ（Chromium）を入れます。

## 起動方法

```bash
bash run.sh
```

ブラウザで `http://<サーバーの IP>:8000/` を開きます。

### 設定（環境変数）

| 変数 | 既定 | 内容 |
|---|---|---|
| `PORT` | `8000` | 待ち受けるポート |
| `DATA_DIR` | `./data` | データの保存先。無ければ作ります。`app.db`（データベース）と `secret_key`（セッションの鍵）ができます |

例: `PORT=9000 DATA_DIR=/var/lib/equipment-lending bash run.sh`

## 初期ユーザー

初期状態では備品もアカウントも 0 件で、初期ユーザーのような固定のアカウントはありません。

1. `/accounts/register/` で社員番号（6 桁の数字）、名前（30 文字以内）、パスワード（8 文字以上）を入力して登録します。
2. アカウントが 1 件も無いときに登録した人は**担当者**になり、2 件目以降に登録した人は**社員**になります。最初に登録する人が担当者になるので、その人が備品の登録と貸出の管理を行います。
3. 担当者でログインし、`/equipment/new/` から備品を登録します（管理番号は半角の英数字とハイフン、20 文字以内）。

## 運用

- 社内のネットワークからだけ開けるように運用してください。サーバーは全てのネットワークインターフェースで待ち受けます（`0.0.0.0`）。外部へ公開する設定にはしないでください。
- データは `DATA_DIR` の `app.db` に保存されます。バックアップはこのファイルを対象にしてください。

## テスト

```bash
.venv/bin/python -m pytest tests -q                              # 単体・結合テスト
.venv/bin/python -m pytest e2e -q --junitxml=e2e/results/e2e.xml  # E2E テスト（ブラウザを使う）
bash scripts/isdd/check.sh --strict                              # 対応表と依存の規則のチェック
```

設計と要件の対応は `docs/` にあります（`requirements.md`・`detail_design.md`・`trace_map.md`）。
