# Wheel of Fortune

ブラウザでホイールを回して景品を当てる Web サイトです。景品の一覧を見られ、利用者名ごとに自分の抽選記録を確かめられます。

## 必要なもの

- Python 3.9 以上（開発と確認は Python 3.12）。外部パッケージは使いません。
- Chromium 系のブラウザ

## 起動方法

```bash
bash setup.sh
PORT=8000 bash run.sh
```

ブラウザで `http://127.0.0.1:8000` を開きます。`PORT` を省略すると 8000 番を使います。サーバーは前景で動くため、止めるときは Ctrl+C を押します。

### 環境変数

| 名前 | 用途 | 既定値 |
|---|---|---|
| `PORT` | 待ち受けポート（127.0.0.1） | 8000 |
| `DATA_DIR` | データベースファイル（`wheel.sqlite3`）の置き場所。無ければ作る | プロジェクトルートの `data` |

`DATA_DIR` にデータベースが無いときだけ、サンプルの景品 6 件を入れます。すでにあるときは何も入れません。

## 画面

画面上部のメニューから移動します（英語表示）。背景はアイボリー、部品は濃い緑です。

- **Spin**: 利用者名（1〜30 文字）を入力して Spin を押すと、ホイールが回って景品が 1 つ決まります。利用者名が空や空白だけのときは回らず、入力欄の下にメッセージを出します。結果は抽選記録として残ります。利用者名はブラウザに保存されます。
- **Prizes**: 景品の名前と説明の一覧です。
- **My Records**: 利用者名を入力して Search を押すと、その名前の抽選記録を新しい順に表示します。表は利用者名・景品名・抽選日時を並べます。Clear records を押すと確認のダイアログが出ます。OK を押すと、利用者名に関係なくすべての抽選記録が消えます（景品は消えません）。
- **Manage prizes**: 景品名を入力して Add を押すと景品が 1 件増えます（名前は 1〜60 文字）。一覧の Remove を押すと景品が 1 件消えます（確認は出ません）。消した景品の抽選記録は My Records に残ります。Spin のホイールと Prizes の一覧は、画面を開くたびに今の景品の一覧を読み直して描きます。

ログインはありません。記録は利用者名の完全一致で区別します。

## テスト

```bash
python3 -m unittest discover -s tests
python3 scripts/isdd/unittest_junit.py -s e2e -o e2e/results/e2e.xml
```

E2E テストは一時的な DATA_DIR と空きポートで実サーバーを起動して、HTTP で動作を確かめます。
