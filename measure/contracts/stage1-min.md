# 採点の契約（計測 5 用の最小版: 技術的な接点だけ。文言や振る舞いの規則は書かない）

採点は自動で行う。ここに書いた起動方法・URL・要素の id とクラス名は守ること。文言や振る舞いの規則はここには書かないので、依頼者に確認して決めること。

## 起動

- プロジェクトルートに `run.sh` を置く。`bash run.sh` で Web アプリが起動し、環境変数 `PORT`（既定 8000）で待ち受ける。
- 環境変数 `DATA_DIR` にデータ（DB ファイルなど）を置く。無ければ作る。空なら、備品もアカウントも 0 件の状態で始まる。
- 環境変数 `SESSION_IDLE_TIMEOUT_SECONDS` で、操作しないまま自動でログアウトするまでの秒数を変えられる（既定 1800）。
- 起動に必要な準備（依存の導入など）は `bash setup.sh` で行う。採点の前に 1 回だけ実行する。
- 外部のサービスや有償のものを使わない。Python 3.12 と無償のライブラリ、SQLite などのファイル DB で足りるようにする。

## 画面の URL

| 画面 | URL |
|---|---|
| 貸出状況（トップ） | `/` |
| アカウント登録 | `/accounts/register/` |
| ログイン | `/login/` |
| 備品の登録 | `/equipment/new/` |

備品の修正・削除は、貸出状況の一覧の行のボタンから行う（URL は自由）。

## 画面の要素の id とクラス名

- 入力欄の id: 社員番号 `id_employee_number`、名前 `id_name`、パスワード `id_password`、管理番号 `id_equipment_number`、備品名 `id_name`。
- 入力欄ごとのエラーは、入力欄を含む `.field` 要素の中の `.field-error` 要素に出す。画面全体のエラーは `.error` 要素、操作の結果の知らせは `.message` 要素、ログイン中の利用者名は `.current-user` 要素に出す。
- 貸出状況の表は `tbody tr` で、各行に `data-equipment-number="<管理番号>"` を付ける。
