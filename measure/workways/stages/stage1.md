# 依頼: 社用車の予約

営業所の社用車 3 台の予約を、いまは事務所のホワイトボードに書いて管理しています。これをアプリにして、自分の席や外出先からでも予約できるようにしてください。使うのは営業所の約 20 人で、社内のネットワークからブラウザで開きます。ログインは要りません（名前は自分で入れます）。

## 予約に書く項目

いまホワイトボードに書いている項目は次のとおりです。アプリでも同じ項目を持たせてください。

| 項目 | 中身 |
|---|---|
| 車 | 予約する車 |
| 日付 | 使う日 |
| 開始時刻・終了時刻 | 使う時間（分単位） |
| 名前 | 使う人の名前。30 文字以内 |
| 行き先 | 50 文字以内 |

## 作ってほしいこと

- 車を登録する（番号と名前）。
- 予約を入れる。同じ車で時間が重なる予約は入れられない。
- 日付を選んで、その日の予約を見る。
- 予約を取り消す。

採点のために `contract.md` の契約を守ってください。
