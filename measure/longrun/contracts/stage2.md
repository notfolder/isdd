# 採点の契約（画面の接点と文言）

採点は、この契約に沿って自動で行う。契約を守らないと、機能が正しくても採点で落ちる。
ここに書くのは画面の接点（起動方法、URL、要素の id、ボタンと表示の文言）だけ。

## 起動

- プロジェクトルートに `run.sh` を置く。`bash run.sh` で Web アプリが起動し、環境変数 `PORT`（既定 8000）で待ち受ける。
- 環境変数 `DATA_DIR` にデータ（DB ファイルなど）を置く。無ければ作る。空なら、備品もアカウントも 0 件の状態で始まる。
- 起動に必要な準備（依存の導入など）は `bash setup.sh` で行う。採点の前に 1 回だけ実行する。
- 外部のサービスや有償のものを使わない。Python 3.12 と無償のライブラリ、SQLite などのファイル DB で足りるようにする。
- 日付は日本時間で扱う。

## 画面の URL

| 画面 | URL |
|---|---|
| 貸出状況（トップ） | `/` |
| アカウント登録 | `/accounts/register/` |
| ログイン | `/login/` |
| 備品の登録 | `/equipment/new/` |

備品の修正・削除、貸出、返却は、貸出状況の一覧の行のボタンから行う（貸出の登録画面と修正画面の URL は自由）。

## 画面の要素（id・文言は一致させる）

- 入力欄の id: 社員番号 `id_employee_number`、名前 `id_name`、パスワード `id_password`、管理番号 `id_equipment_number`、備品名 `id_name`、借りる社員 `id_borrower`（select。選択肢の表示は「名前（社員番号）」）、貸出日 `id_lent_on`（`YYYY-MM-DD`、既定は今日）。
- ボタンの文言: アカウント登録「登録」、ログイン「ログイン」、ログアウト「ログアウト」、備品の登録と修正の保存「保存」、貸出の登録「登録」、行の操作「修正」「削除」「貸出」（空きの備品）「返却」（貸出中の備品）。
- 行のボタンは、ログインしている利用者がその操作を行えるときだけ、その行に出す。ログインしていないときは画面にボタンを出さない（「ログイン」「アカウント登録」はリンク）。
- 備品の登録画面への入口は「備品を登録」（リンクにする。登録できる利用者だけに出す）。
- 入力欄ごとのエラーは、入力欄を含む `.field` 要素の中の `.field-error` 要素に出す。入力した値は消さない。
- 画面全体のエラーは `.error` 要素、操作の結果の知らせは `.message` 要素に出す。
- 操作を受け付けないときは、理由を `.field-error`・`.error`・`.message` のどれかに出し、データを変えない（文言は自由）。
- ログイン中は `.current-user` 要素に名前を出す。
- 貸出状況の表は `tbody tr` で、各行に `data-equipment-number="<管理番号>"` を付け、管理番号の昇順に並べる。行には管理番号、備品名、状態（空いていれば「空き」、貸し出していれば「貸出中」）、借りている社員の名前、貸出日（`YYYY-MM-DD`）の列を出す。備品が 0 件なら「備品は登録されていません」と出す。
- 削除と返却は、ブラウザの確認ダイアログ（`window.confirm`）で「はい」のときだけ行う。
- 貸出の登録に成功したら、貸出状況の画面（`/`）に移る。

## 文言（完全一致）

| 場面 | 文言 |
|---|---|
| アカウント登録の成功（ログイン画面に移って表示） | 登録しました。ログインしてください |
| ログインの失敗（`.error`） | 社員番号またはパスワードが違います |

## 依頼 2 で足す接点（返却の期限）

- 貸出状況の表の各行に、返却の期限の列を足す。そのセルに class `due-date` を付け、日付を `YYYY-MM-DD` で出す（空きの行は空欄）。
- 状態の文言に「期限超過」を足す。
