# 採点の契約（段 2: 貸出と返却。段 1 の契約に追加する）

採点は、この契約に沿って自動で行う。契約に無いことは自由に決めてよい。契約を守らないと、機能が正しくても採点で落ちる。
段 1 の契約（起動、URL、要素、文言）はそのまま有効。ここには段 2 で足す分と、変わる分だけを書く。

## 起動

段 1 と同じ（`setup.sh`、`run.sh`、`PORT`、`DATA_DIR`、`SESSION_IDLE_TIMEOUT_SECONDS`）。

## 画面の URL

段 1 と同じ。貸出・返却は、貸出状況の一覧の行のボタンから行う（貸出の登録画面の URL は自由）。

## 画面の要素（追加分）

- 入力欄の id: 借りる社員 `id_borrower`（select。選択肢の表示は「名前（社員番号）」）、貸出日 `id_lent_on`（`YYYY-MM-DD`、既定は日本時間の今日）。
- ボタンの文言: 貸出の登録「登録」、行の操作「貸出」（空きの備品）「返却」（貸出中の備品）。担当者だけに出す。
- 貸出の登録画面には `.lending-equipment` 要素に「備品: <管理番号> <備品名>」を出す。
- 貸出状況の表の各行に、貸出中なら「貸出中」、借りている社員の名前、貸出日（`YYYY-MM-DD`）を出す（段 1 で用意した列を実際に使う）。
- 画面全体のエラー（他の担当者が先に更新した）は `.error` 要素に出す。
- 操作の結果の知らせ（「この備品は既に貸出中です」など）は `.message` 要素に出す。
- 返却は、ブラウザの確認ダイアログ（`window.confirm`）で「はい」のときだけ行う。

## 文言（完全一致、追加分）

| 場面 | 文言 |
|---|---|
| 他の担当者が先に更新・削除した（修正の保存で `.error` に出す） | 他の担当者が先にこの備品を更新しました。貸出状況の画面から開き直してください |
| 貸出中の備品の削除（貸出状況の画面の `.message` に出す） | この備品は貸出中のため削除できません。先に返却を処理してください |
| 借りる社員が未選択（`.field-error`） | 借りる社員を選んでください |
| 未来の貸出日（`.field-error`） | 貸出日に未来の日付は入力できません |
| 貸出中の備品の貸出（貸出状況の画面の `.message` に出す） | この備品は既に貸出中です |
| 返却済みの備品の返却（貸出状況の画面の `.message` に出す） | この備品は既に返却されています |
