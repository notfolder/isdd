# 依頼: まるいち物産の API が新しくなるので、対応してほしい

まるいち物産から、下の通知が届きました。在庫照会の API が v2 に変わり、v1 は使えなくなるそうです。今のアプリを v2 で動くように直してください。使い方は今までどおりにしたいです。

採点のために `contract.md` の契約を守ること。採点では、接続先は v2 だけが動いています（v1 は終了しています）。

---

## まるいち物産からの通知（在庫照会 API v2 への移行のお願い）

発行: まるいち物産 情報システム部

在庫照会 API を v2 に切り替えます。v1 は終了し、終了後は `410` を返します。検証環境では v2 をすでにお使いいただけます（接続先の URL と資格情報は v1 と同じです）。

### 変わること

1. パスが `/v2/` になります。認証は `POST /v2/auth/token`（要求と応答は v1 と同じ）、照会は `GET /v2/items` です。
2. ページの指定が、ページ番号からカーソルに変わります。

   `GET /v2/items?limit=<1 回の件数>&cursor=<カーソル>`

   | パラメータ | 説明 |
   |---|---|
   | `limit` | 1 回の件数。省略時は 20、上限は 50 |
   | `cursor` | 前の応答の `next_cursor`。最初の照会では付けない |

   応答（200）:

   ```json
   {
     "items": [
       {"code": "MB-00001", "name": "六角ボルト M8×25", "stock": {"available": 100, "reserved": 20}, "status": "active"}
     ],
     "next_cursor": "MB-00001"
   }
   ```

   続きがあるときは `next_cursor` を次の照会の `cursor` に渡してください。最後のページでは `next_cursor` は `null` です。`page`・`per_page`・`total` は無くなります。
3. 在庫数 `stock` が、内訳つきになります。`available` は引き当てできる数、`reserved` は他のお客様の注文で引き当て済みの数です。
4. 商品の状態 `status` が付きます。`active`（販売中）か `discontinued`（廃番）です。廃番の商品も返します。
5. 回数の制限が、トークンごとに 1 秒あたり 2 回までになります。超えたときの扱い（`429` と `Retry-After`）は変わりません。

### 変わらないこと

- トークンの失効（`401` `token_expired`）、障害時の `503` は v1 と同じです。
