# 依頼者の隠し台帳（計測 5、お題 1 の段 1）

依頼者役はこの台帳の範囲でだけ答える。聞かれていないことは言わない。台帳に無いことは「分からない。任せる」と答える。

| 番号 | 項目（依頼文に書いていないこと） | 依頼者の答え |
|---|---|---|
| L1 | 社員番号の形式が違うときの文言 | 「社員番号は 6 桁の数字で入力してください」 |
| L2 | 社員番号が重複したときの文言 | 「この社員番号は既に登録されています」 |
| L3 | 名前が空のときの文言 | 「名前を入力してください」 |
| L4 | 名前が長いときの文言 | 「名前は 30 文字以内で入力してください」 |
| L5 | パスワードが短いときの文言 | 「パスワードは 8 文字以上で入力してください」 |
| L6 | 登録に成功したらどうなるか | ログイン画面に移り「登録しました。ログインしてください」と出す |
| L7 | ログインに失敗したときの文言 | 「社員番号またはパスワードが違います」（どちらが違うかは示さない） |
| L8 | 入力エラーのとき、入力した値はどうするか | 消さずに残す（パスワードも含めてよい） |
| L9 | 担当者以外が備品の登録画面などを開いたら | 貸出状況の画面に戻して「この操作は担当者だけが行えます」と出す。ログインしていなければログイン画面へ |
| L10 | 管理番号の形式が違うときの文言 | 「管理番号は半角の英数字とハイフンで 20 文字以内で入力してください」 |
| L11 | 管理番号が重複したときの文言 | 「この管理番号は既に使われています」 |
| L12 | 備品名が長いときの文言 | 「備品名は 50 文字以内で入力してください」 |
| L13 | 貸出状況の一覧の並び順 | 管理番号の昇順 |
| L14 | 備品が 0 件のときの表示 | 「備品は登録されていません」 |
| L15 | 削除の確認 | ブラウザの確認ダイアログで「はい」のときだけ消す |
| L16 | ボタンとリンクの文言 | アカウント登録「登録」、ログイン「ログイン」、ログアウト「ログアウト」、保存「保存」、行の操作「修正」「削除」、備品の登録画面への入口「備品を登録」、トップの「ログイン」「アカウント登録」はリンク |
| L17 | ログインしていない人に見せるもの | 一覧は見せる。ボタンは一切出さない（リンクだけ） |
| L18 | 一覧の列 | 管理番号、備品名、「空き」または「貸出中」、借りている社員の名前、貸出日（今は全部「空き」で名前と日付は空欄） |
| L19 | 備品名が空のときの文言 | （台帳に無い: 分からない、任せる） |
| L20 | 管理番号の大文字と小文字 | （台帳に無い: 分からない、任せる） |
